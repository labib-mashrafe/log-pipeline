LINE TYPES I SAW --
1. reverse mapping check - has: address, example: line 1
2. Invalid user - has: username, address, example: line 2, 9
3. input_userauth_request - has: username, example: line 3, 10
4. pam check pass - has: nothing useful, example: line 4
5. pam authentication failure - has: address (rhost=), example: line 5
6. Failed password - has: username, address, port, example: line 6
7. Connection closed - has: address, example: line 7, 8

Failed password lines are the best way to count failed logins. Why? -- Every time someone enters a wrong password, the log shows a line starting with "Failed password". Other lines from the same attempt, like "authentication failure" and "Invalid user", also appear, so counting them too would count one attempt several times. "Failed password" appears once per wrong password.
